The tag holds 94 eight-byte records, full after 3 d 22 h at this rate. A 32 KB I²C EEPROM holds 4,096 of them.

Tag memory · MIFARE Classic 1K

64 blocks of 16 bytes, shown by sector. 47 hold data. Block 0 and the 16 sector trailers are reserved. Each data block holds two records, so the MCU writes a block after every second sample.
